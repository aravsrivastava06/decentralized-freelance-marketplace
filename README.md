# Decentralized Freelance Marketplace

A Web3-based escrow-driven freelance marketplace built using Solidity, Hardhat, React, and Ethers.js.

---

## Project Overview

This platform eliminates intermediaries in freelance hiring by using smart contracts for secure and transparent payments.

- Clients post jobs
- Funds are locked in smart contract (escrow)
- Freelancers complete work
- Payment is released automatically

---

## Tech Stack

- Solidity
- Hardhat
- React.js
- Ethers.js
- MetaMask

---

## Workflow

1. Client posts job and deposits ETH  
2. Freelancer accepts job  
3. Freelancer submits work  
4. Client approves work  
5. Smart contract releases payment
